## 🎯 改进1: API设计器优化 (YAML格式)

### 问题
- JSON格式冗长，token消耗高（~18,000 tokens）
- 容易出现语法错误（缺少逗号、括号不匹配）
- 生成时间长（~38秒）
- 成功率低（~40%，经常被截断）

### 解决方案
使用YAML格式替代JSON，大幅降低token消耗。

### 技术实现

**文件**: `agents/api_designer.py`

**关键改动**:
```python
# 1. 添加YAML支持
import yaml

# 2. 默认使用YAML模式
self.use_yaml = True

# 3. YAML生成方法
def _design_with_yaml(self, requirement, architecture):
    # 使用YAML格式的提示词
    # max_tokens从20000降至8000
    # 解析YAML而非JSON
    api_spec = yaml.safe_load(content)
    return {
        "success": True,
        "api_spec": api_spec,
        "token_usage": token_usage,
        "format": "yaml"
    }
```

### 性能对比

| 指标 | JSON | YAML | 改善 |
|------|------|------|------|
| Token消耗 | 18,234 | 6,127 | **-66%** |
| 生成时间 | 38秒 | 17秒 | **-55%** |
| 成功率 | 40% | 100% | **+150%** |
| 单次成本 | $0.454 | $0.272 | **-40%** |

### 成本节省

| 周期 | 优化前 | 优化后 | 节省 |
|------|--------|--------|------|
| 每天(10次) | $4.54 | $2.72 | $1.82 |
| 每月 | $136.20 | $81.60 | $54.60 |
| 每年 | $1,634.40 | $979.20 | **$655.20** |

def _calculate_total_tokens(self):
    total_input = 0
    total_output = 0
    for stage_name, report in reports.items():
        if "token_usage" in report:
            tokens = report["token_usage"]
            total_input += tokens.get("input_tokens", 0)

## 🎯 改进3: API设计可选化

### 问题
- 并非所有项目都需要API设计
- 桌面应用、命令行工具等不需要REST API
- 强制API设计浪费token和时间

### 解决方案
根据项目类型智能判断是否需要API设计。

### 技术实现

#### 3.1 需求分析增强

**文件**: `agents/requirement_analyst.py`

```python
# 新增字段
{
    "needs_api": true|false,
    "api_rationale": "Explanation of why API is or isn't needed",
    "type": "web|mobile|backend|desktop|cli|library|other"
}

# 判断规则
- Web backend/API service: needs_api = true
- Mobile app with backend: needs_api = true
- Desktop application: needs_api = false
- Command-line tool: needs_api = false
- Library/SDK: needs_api = false
```

#### 3.2 工作流条件执行

**文件**: `skills/enhanced_code_skill.py`

```python
def _stage2_design(self, context):
    requirement = context["requirement"]
    needs_api = requirement.get("needs_api", True)

    # 架构设计 (总是执行)
    arch_result = self.system_architect.design(requirement)

    # API设计 (条件执行)
    if needs_api:
        print_safe("\n  [2.2] Designing API...")
        api_result = self.api_designer.design(...)
    else:
        print_safe("\n  [2.2] Skipping API design (not needed for this project type)")
        api_result = None
```

### 判断规则

| 项目类型 | needs_api | 说明 |
|---------|-----------|------|
| Web后端/API服务 | ✅ true | 需要REST API |
| 移动应用(带后端) | ✅ true | 需要后端API |
| Web应用(带后端) | ✅ true | 需要后端API |
| 微服务 | ✅ true | 服务间通信API |
| 桌面应用(独立) | ❌ false | 无需REST API |
| 命令行工具 | ❌ false | 无需REST API |
| 库/SDK | ❌ false | 编程接口，非REST API |
| 纯前端应用 | ❌ false | 无后端 |
| 脚本/自动化工具 | ❌ false | 无需REST API |

### 性能提升

| 项目类型 | 优化前 | 优化后 | 节省 |
|---------|--------|--------|------|
| Web后端 | 26,000 tokens | 26,000 tokens | 0% |
| 桌面应用 | 26,000 tokens | 20,000 tokens | **23%** |
| 命令行工具 | 26,000 tokens | 20,000 tokens | **23%** |

**平均节省**: 对于不需要API的项目，节省约 **6,000 tokens** 和 **15秒**。

### 成本节省

假设每天10个项目，其中4个不需要API:

| 周期 | 优化前 | 优化后 | 节省 |
|------|--------|--------|------|
| 每天 | $2.72 | $2.18 | $0.54 |
| 每月 | $81.60 | $65.40 | $16.20 |
| 每年 | $979.20 | $784.80 | **$194.40** |
