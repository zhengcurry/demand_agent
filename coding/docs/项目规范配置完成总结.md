### 3. Token使用追踪规范

**所有调用Claude API的地方都必须**:

```python
# 1. 提取token使用信息
token_usage = {
    "input_tokens": response.usage.input_tokens,
    "output_tokens": response.usage.output_tokens,
    "total_tokens": response.usage.input_tokens + response.usage.output_tokens
}

# 2. 在返回值中包含
return {
    "success": True,
    "data": result,
    "token_usage": token_usage,
    "format": "yaml"
}

# 3. 在控制台显示
print_safe(f"  ✅ Task completed ({format.upper()} format)")
print_safe(f"     Tokens: {input_tokens} input + {output_tokens} output = {total_tokens} total")
```

### 4. 控制台输出规范

**必须使用 `print_safe()`**:
```python
from utils import print_safe

# ✅ 正确
print_safe("🚀 Starting workflow...")

# ❌ 错误
print("🚀 Starting workflow...")
```

**格式标准**:
```python
# 阶段标题
print_safe("\n" + "=" * 70)
print_safe("🚀 Starting Workflow")
print_safe("=" * 70)

# 进度显示
print_safe("\n[2/6] Design Phase")
print_safe("  [2.1] Designing architecture...")
print_safe("  ✅ Architecture designed")

# Token信息
print_safe(f"     Tokens: {input} input + {output} output = {total} total")
```

### 5. 返回值格式规范

**成功返回**:
```python
{
    "success": True,
    "data": {...},
    "token_usage": {
        "input_tokens": 1234,
        "output_tokens": 567,
        "total_tokens": 1801
    },
    "format": "yaml",
    "timestamp": "2026-01-29T10:30:00"
}
```

**失败返回**:
```python
{
    "success": False,
    "error": "错误描述",
    "details": {...},
    "stage": "api_design",
    "timestamp": "2026-01-29T10:30:00"
}
```
